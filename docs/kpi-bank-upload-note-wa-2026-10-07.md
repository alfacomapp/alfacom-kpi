# KPI: lampiran bank dan notifikasi Notes, 7 Oktober 2026

Perubahan memakai frontend produksi `fd3236a` dan Edge `kpi-api` versi 10 sebagai dasar. Tidak ada perubahan pada frontend, API, tabel, trigger atau penjadwal milik SLA.

- Laporan akun bank menerima maksimal **50 file gabungan** bukti akun dan statement PDF, dengan **10 MiB total per laporan**. Batas diperiksa di browser dan backend dari ukuran base64 sebenarnya. Modul lain mempertahankan batas sebelumnya.
- Statement PDF opsional disimpan pada grup `bankStatement` di laporan dan `bankStatement_<bank>` di tugas pekanan. Riwayat BRI, Mandiri dan Bank Sultra tetap tergabung; penyelesaian tiga bank tetap berlaku.
- Semua file dikirim ke bucket Supabase privat `kpi-uploads`. Metadata tersimpan di `kpi_reports`/`kpi_tasks`. Lihat dan unduh menggunakan pemeriksaan sesi/peran `apiGetUploadedFile` yang sudah ada. Tidak ada tautan Storage publik.
- Jika total melebihi 10 MiB, gambar diperkecil di browser. PDF diproses dengan pdf-lib 1.17.1 lokal: gambar JPEG/RGB/Gray yang didukung diperkecil, teks/font/halaman dipertahankan. PDF di bawah batas tidak diubah. PDF bertanda tangan digital, berpassword, encoding gambar yang tidak didukung, atau hasil yang masih terlalu besar dapat ditolak dengan pesan jelas. File asli di perangkat tidak diubah. Pratinjau dan unduh salinan yang akan dikirim tersedia sebelum submit.
- Kegagalan sebagian upload menghapus hanya objek baru yang sudah diunggah; laporan belum ditulis. Kegagalan penyimpanan laporan tetap memakai cleanup yang ada.

Notes yang ditugaskan membuat antrean `kpi_note_notifications` melalui trigger INSERT pada `kpi_notes`, dalam transaksi penyimpanan yang sama. Tidak ada backfill Notes lama. Notes tanpa penugasan tidak mengirim WA. Setelah transaksi berhasil, Edge mengambil lease dan mengirim melalui Fonnte menggunakan secret proyek `FONNTE_TOKEN`/`FONNTE_TOKEN_CADANGAN`. Penerima diambil dari tepat satu profil `public.users` sesuai pemetaan peran/cabang KPI yang sudah digunakan saat login; nomor dari browser tidak digunakan. Pilihan Sales Director (Penawaran) diarahkan ke akun sales director sebenarnya.

Sukses berarti provider menerima pesan untuk dikirim, bukan bukti sudah dibaca/diterima ponsel. Gagal kirim tetap mempertahankan Notes/tugas dan antrean; trigger harian KPI yang sudah ada mencoba kembali hingga lima entri pada setiap pemanggilan maintenance. Tidak ada perubahan penjadwal SLA. Lease dan status accepted mencegah pengiriman bersamaan atau mengulang pesan yang tercatat sukses. Jika provider menerima pesan tetapi koneksi/ack database terputus, pengulangan setelah lease berakhir masih mungkin karena provider tidak menyediakan transaksi yang sama dengan database.

Antrean menggunakan RLS dan izin hanya service_role. Fungsi antrean SECURITY INVOKER; anon/authenticated tidak diberi EXECUTE. Skema `kpi_*`, bucket privat, RPC revision, autentikasi, pembatasan owner dan pekerjaan harian yang ada dipertahankan.

Verifikasi lokal: tes batas jumlah/ukuran gabungan, validasi PDF, riwayat tiga bank, akses metadata, cleanup upload, pengiriman WA setelah commit, penerima ambigu, tanpa penugasan, provider gagal, dan penugasan khusus sales. Uji antrean Postgres memeriksa transaksi, lease, retry, status accepted, akses privat dan cascade saat note dihapus. Uji Chrome memeriksa kompresi PDF nyata 27.9 MB menjadi 7.54 MB, isi stream teks ketiga halaman identik, gabungan foto/PDF di bawah batas, pratinjau, submit/reset, serta desktop/ponsel tanpa error konsol. Tes SLA terkait absensi/slip/profil lulus 41/41. Tes lobby lama memiliki satu kegagalan baseline karena mengharapkan bridge lama tertanam verbatim pada index.html; file SLA tersebut tidak diubah.

Status penerapan: `kpi-api` versi **11** sudah aktif dengan autentikasi custom sebelumnya; source hasil deploy identik setelah normalisasi akhir baris. Migrasi antrean sudah terpasang, RLS aktif, akses anon/authenticated ditolak. GitHub Pages selesai deploy dan mengembalikan HTTP 200 untuk halaman, modul kompresi, serta pustaka PDF. Uji produksi CORS mendapat 204, sesi palsu ditolak 401, pemicu tanpa kunci server ditolak 403. Hash enam file utama SLA identik. Uji browser pratinjau PDF tersimpan dan unduh nama file berhasil; sandbox pengujian semula membatalkan semua unduhan termasuk teks sederhana, sehingga uji unduh dijalankan ulang dengan akses folder hasil tes. PDF tanpa MIME browser dinormalisasi tanpa mengubah byte dokumen. Notifikasi WA telah diuji dengan provider tiruan; belum ada Notes baru untuk mengonfirmasi pengiriman nyata ke ponsel pada saat pemeriksaan antrean.
